# OpenAI Build Week submission checklist — Board Game Computer

## Administrative

- [ ] Devpost draft exists in **Apps for Your Life**.
- [ ] Eligibility and country are confirmed against the official rules.
- [ ] Primary Codex build session is retained.
- [ ] `/feedback` Session ID is saved for the submission form.
- [ ] OpenAI API project and Cloudflare deployment are active.

## Required submission materials

- [ ] Working free demo URL.
- [ ] Category selected.
- [ ] English project description rewritten in the author's voice.
- [ ] Public YouTube video under three minutes with audio.
- [ ] Video shows the working project and explains Codex and GPT-5.6 usage.
- [ ] Repository URL is public with a license, or private access is granted to
      `testing@devpost.com` and `build-week-event@openai.com`.
- [ ] README includes setup, sample data, Codex collaboration, human decisions,
      and GPT-5.6 integration.
- [ ] Codex `/feedback` Session ID entered.
- [ ] No unlicensed trademarks, music, rules text, or art.
- [ ] All submission materials are in English.

## Production QA

- [ ] Clean/incognito desktop judge path passes.
- [ ] Clean/incognito mobile judge path passes.
- [ ] No login, BYOK, CAPTCHA, or WAF challenge.
- [ ] Live AI, timeout, repair, fallback, reset, and fresh-copy paths pass.
- [ ] Production URL matches the video and copy.
- [ ] API budget and kill switch are configured.
- [ ] No secret appears in repo, bundle, source maps, logs, screenshots, or video.

## Evidence and release

- [ ] Eligibility auditor prompt run.
- [ ] Rubric grader prompt run.
- [ ] First-impression judge prompt run.
- [ ] Browser agent follows `JUDGING.md` successfully.
- [ ] Evidence matrix filled with real files/URLs/timestamps.
- [ ] Submission commit recorded.
- [ ] Tag `build-week-submission` created and pushed.
- [ ] YouTube HD processing completed and link checked in incognito.
- [ ] Devpost status is **Submitted**, not Draft.
- [ ] Public submission view checked after final save.

## Deadline and post-deadline

- [ ] Submit before **2026-07-22 04:00 Asia/Tbilisi**.
- [ ] Do not make risky production changes after the submission deadline.
- [ ] Keep the demo available free of charge through the judging period.
- [ ] Preserve a rollback path to the tagged submission release.
